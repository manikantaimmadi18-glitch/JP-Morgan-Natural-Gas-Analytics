# J.P. Morgan Data Analytics Virtual Experience

## Project Overview
This repository contains my solutions for the J.P. Morgan Data Analytics Virtual Experience Program. The project demonstrates data analysis, financial modeling, and credit risk analysis using Python.

## Tasks Completed

### Task 1: Natural Gas Price Forecasting
- Analyzed historical natural gas prices.
- Forecasted future prices.
- Visualized trends using Matplotlib.

### Task 2: Storage Contract Pricing
- Built a pricing model for natural gas storage contracts.
- Calculated contract profitability considering storage and transportation costs.

### Task 3: Credit Risk Model
- Estimated probability of default using financial data.
- Performed credit risk analysis.

### Task 4: FICO Score Quantization
- Categorized FICO credit scores into risk buckets.
- Improved credit score interpretation.
