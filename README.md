# Natural Gas Price Forecasting & Storage Pricing Model

## Project Overview

This project was completed as part of the J.P. Morgan Data Analytics Virtual Experience Program. The objective was to analyze historical natural gas prices, forecast future prices, and build a pricing model to estimate the profitability of natural gas storage contracts.

## Objectives

* Analyze historical natural gas price data.
* Visualize monthly price trends.
* Forecast future natural gas prices.
* Develop a storage contract pricing model.
* Calculate the expected profit or loss of storage contracts.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* VS Code
* Git
* GitHub

## Project Files

* `task1_price_forecasting.py` – Analyzes historical natural gas prices and creates visualizations.
* `task2_storage_pricing.py` – Calculates the value of storage contracts based on purchase price, selling price, storage costs, transportation costs, injection costs, and withdrawal costs.
* `Nat_Gas.csv` – Historical natural gas price dataset.

## Workflow

1. Import and preprocess the dataset.
2. Analyze historical price trends.
3. Visualize the data using charts.
4. Forecast future natural gas prices.
5. Calculate the profitability of storage contracts.
6. Display the final contract values.
